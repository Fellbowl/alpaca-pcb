# ch224k.c - Driver Controlador de Voltaje CH224K

## Descripción General
Driver para el controlador de voltaje USB PD (Power Delivery) CH224K.

Proporciona:
- Selección de voltaje de salida (5V, 9V, 12V, 15V, 20V)
- Lectura de Power Good (PG) mediante GPIO
- Monitoreo de voltaje opcional mediante ADC
- Detección de disponibilidad del controlador

## Configuración de Hardware

### GPIOs de Salida (Configuración)
- **CFG1**: GPIO de salida (selección de voltaje)
- **CFG2**: GPIO de salida (selección de voltaje)
- **CFG3**: GPIO de salida (selección de voltaje)

### GPIO de Entrada (Feedback)
- **PG (Power Good)**: GPIO de entrada con pull-up
  - Bajo = Voltaje disponible y en rango
  - Alto = Sin voltaje o fuera de rango

### ADC (Opcional)
- **Unidad ADC**: Configurable (ADC1 o ADC2)
- **Canal ADC**: Configurable
- **Atenuación**: ADC_ATTEN_DB_12 (hasta ~3.3V)

## Función Principal

### `ch224k_init(ch224k_t *dev, const ch224k_config_t *cfg)`

**Procedimiento:**
1. Guarda configuración
2. Configura GPIOs de salida (CFG1, CFG2, CFG3) como output
3. Configura GPIO PG como input con pull-up (si `pin_pg >= 0`)
4. Configura ADC si `enable_adc` es true:
   - Inicializa unidad ADC
   - Configura canal con atenuación para 3.3V
5. Establece voltaje por defecto a 5V (seguro)
6. Marca dispositivo como ready

**Retorna:**
- `ESP_OK` si éxito
- `ESP_ERR_INVALID_ARG` si parámetros NULL
- Error de GPIO o ADC si configuración falla

### `ch224k_set_voltage(ch224k_t *dev, ch224k_voltage_t voltage)`

Establece voltaje mediante combinación de CFG1, CFG2, CFG3:

| Voltaje | CFG1 | CFG2 | CFG3 | Descripción |
|---------|------|------|------|-------------|
| 5V      | 1    | 0    | 0    | Voltaje estándar USB |
| 9V      | 0    | 0    | 0    | USB PD 9V |
| 12V     | 0    | 0    | 1    | USB PD 12V |
| 15V     | (...)| (...) | (...) | USB PD 15V |
| 20V     | (...)| (...) | (...) | USB PD 20V, perfil usado por `power_monitor_task` |

**Notas:**
- Cambio de voltaje es inmediato (GPIO directo)
- No retorna PG (lectura independiente)
- Establece por defecto 5V al iniciar

## Funciones Adicionales (Esperadas)

### `ch224k_read_power_good(ch224k_t *dev, bool *out_pg_ok)`
Lee nivel de GPIO PG.
- Bajo → `pg_ok = true`
- Alto → `pg_ok = false`

### `ch224k_read_voltage_adc(ch224k_t *dev, uint32_t *out_voltage_mv)`
Lee voltaje de salida mediante ADC si habilitado.

## Gestión de Errores

### Manejo de Fallos
- GPIO configuración fallida: Log ERROR y retorna error
- ADC inicialización fallida: Log ERROR, libera unidad ADC
- PG opcional: Si `pin_pg < 0`, omite configuración GPIO entrada

### Logging
- TAG: "CH224K"
- Nivel ERROR: Fallos de configuración
- Nivel INFO: Inicialización exitosa

## Diseño Modular

**Público:**
- Inicialización
- Selección de voltaje
- Lectura de estado (PG, ADC)

**Privado:**
- Mapeo específico CFG1/CFG2/CFG3 a voltajes
- Detalles de configuración ADC

## Integración con Sistema

### Power Good Monitor
En main.c:
- `power_monitor_task` lee PG periódicamente
- Da semáforo a `motor_task` cuando PG = true
- Garantiza voltaje disponible antes de energizar motor

### Seguridad
- Voltaje por defecto 5V (más seguro si inicialización interrumpida)
- Sin PG confirmado, motor nunca se energiza
- Protección contra arranque con voltaje insuficiente

## Dependencias

- ESP-IDF drivers:
  - `driver/gpio.h`: Configuración GPIO
  - `esp_adc/adc_oneshot.h`: Lectura ADC (opcional)
- `esp_log.h`: Logging

## Notas de Operación

1. **ADC opcional:** Permite monitoreo de voltaje real de salida
2. **PG opcional:** Si no disponible, motor_task nunca arrancaría
3. **Voltajes soportados:** 5V, 9V, 12V, 15V y 20V; la fuente USB-PD debe soportar el perfil solicitado
4. **Cambio dinámico:** Puedes cambiar voltaje durante operación
