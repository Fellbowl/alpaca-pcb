# as5600.c - Driver Encoder Magnético AS5600

## Descripción General
Driver I2C para encoder magnético rotatorio AS5600.

Características:
- Comunicación I2C a 400 kHz
- Resolución de 12 bits (4096 valores)
- Rango: 0° a 360°
- Detección de imán magnético
- Conveniente para feedback de posición en focuser

## Protocolo AS5600

### Dirección I2C
- **Dirección**: `0x36` (fija, no configurable)

### Registros Principales
- **0x0B (STATUS)**: Byte de estado
  - Bit 5 (0x20): MD (Magnet Detected)
  - Bit 4 (0x10): ML (Magnet too weak)
  - Bit 3 (0x08): MH (Magnet too strong)

- **0x0C:0x0D (RAW_ANGLE)**: Ángulo sin filtrar
  - 2 bytes, 12 bits útiles (los 4 superiores descartados)

## Funciones Principales

### `as5600_init(as5600_t *dev, const as5600_config_t *cfg)`
Registra dispositivo en bus I2C compartido.

**Entrada:**
- `dev`: Estructura del dispositivo (salida)
- `cfg`: Configuración con:
  - `bus`: Handle del bus I2C ya creado
  - `i2c_freq_hz`: Frecuencia I2C

**Notas:**
- No crea bus I2C (lo recibe del orquestador, compartido con AHT21B)
- DIR (selección de dirección) fijado a GND por hardware
- Solo se registra como dispositivo en bus existente
- Autocontenido: no sabe de otros módulos

### `as5600_read_status(as5600_t *dev, uint8_t *out_status)`
Lee byte de STATUS del encoder.

**Procedimiento:**
1. Escribe dirección de registro (0x0B)
2. Lee 1 byte de respuesta
3. Retorna estado en `out_status`

**Información obtenida:**
- Presencia de imán (MD)
- Fuerza de imán demasiado débil (ML)
- Fuerza de imán demasiado fuerte (MH)

### `as5600_read_raw_angle(as5600_t *dev, uint16_t *out_raw)`
Lee ángulo crudo sin filtro.

**Procedimiento:**
1. Escribe dirección de registro (0x0C = byte alto)
2. Lee 2 bytes
3. Extrae 12 bits útiles (máscara 0x0FFF)
4. Retorna en `out_raw` (0-4095)

### `as5600_read_angle_deg(as5600_t *dev, float *out_degrees)`
Convierte ángulo crudo a grados.

**Fórmula:**
```
grados = (raw * 360.0) / 4096.0
```

**Rango:**
- Entrada: 0-4095
- Salida: 0.0-359.96 grados

### `as5600_magnet_detected(uint8_t status)`
Verifica si imán detectado en byte de status.

**Retorna:**
- `true` si Bit 5 (0x20) = 1
- `false` si Bit 5 = 0

## Características de Implementación

### Gestión de Memoria
- Device registrado en bus compartido
- No asigna heap (control de bus del orquestador)

### Error Handling
- `ESP_ERR_INVALID_ARG`: Parámetros NULL o bus NULL
- Errores I2C propagados desde `i2c_master_transmit_receive()`

### Logging
- TAG: "AS5600"
- Nivel ERROR: Fallos de comunicación I2C

### Timeouts
- Todas las operaciones I2C: 100 ms timeout

## Diseño Modular

**Privado del módulo:**
- Dirección I2C (0x36)
- Direcciones de registros
- Bits de status

**Público (header):**
- Funciones de alto nivel
- Estructuras de configuración
- Utilidades de lectura de status

**Ventaja:** Protocolo interno no filtra a otros módulos

## Integración con Focuser

### Uso en Sistema
1. Lee posición angular del imán acoplado a eje del focuser
2. Convierte a posición lineal del mecanismo
3. Feedback para validar movimientos del motor
4. Detección de posición para test de inicio (homing)

### Consideraciones
- Imán debe estar correctamente alineado
- Distancia típica: 2-5 mm del sensor
- Fuerza de imán debe estar en rango (no ML ni MH)

## Dependencias

- FreeRTOS: `task.h`, `FreeRTOS.h`
- ESP-IDF drivers:
  - `i2c_master_bus_add_device()`
  - `i2c_master_transmit_receive()`
- `esp_log.h`: Logging
- `esp_check.h`: Macros de error

## Notas de Operación

1. **Detección de disponibilidad:** Usa `as5600_read_status()` como probe en arranque
2. **Bus compartido:** Compatible con AHT21B en I2C_NUM_0
3. **Resolución:** 0.088° por LSB de 12 bits
4. **Velocidad:** Lectura instantánea, sin delay adicional
5. **Integración:** main.c maneja reintentos si encoder no responde
